# dny — 龙与耶维城

四层对抗式增量放置游戏（反物质维度式的多层重置）。玩家在耶维城经营奶茶店，用奶茶净化深渊；
深渊的压迫一旦追平你的净化力，耶维城覆灭、一切回到档 0；净化力打穿本档的深渊总量，就是「守护」，
视野外扩一档并结算一份守护点数。

**本版只做档 0–3（奶茶店 / 耶维城 / 飞龙国 / 奶茶大陆）。**

前端套的是 **反物质维度（AD）的壳**：AD 的 `styles.css` / `old-ui.css`、字体与图标、
`o-primary-btn` / `o-tab-btn` 这套类名约定 + Vue 2 运行时。

## 数值的权威在哪

> **`docs/数值设计.md`（V5）是唯一权威。**
> 代码里 `src/v5.js` 是它的 **逐字实现**（含运算顺序、`Math.expm1` / `Math.log1p` 的调用位置），
> 一个数都不许改。`src/engine.js` 只是外壳（tick 调度、结算接线、存读档、剧情、面板），不参与任何数值计算。

跑出来的结果必须和文档里的参考模拟器**完全一致**：

```text
失败次数：[6,5,6,4]      轮数：22
最终失败等级：F[5,6,6,3]   最终成功等级：U[11,4,1,1]
最终余额：失败 18327 / 成功 5670
累计游戏时间：14997.20 秒，约 4 小时 09 分 57.20 秒
```

## 快速开始

```powershell
node server.mjs 8080        # 浏览器打开 http://127.0.0.1:8080 即可玩
```

零依赖运行（只需要 Node 20+，`vue.min.js` 已随仓库放在 `web/shell/`）。
部署到 2c2g 机器直接 `node server.mjs 80`。

## 玩法要点（全部由 20Hz 结算自动跑）

- **四个量**：净化力 `x`（打穿目标就守护）、深渊 `h`（追平净化力就覆灭）、奶茶币 `mtc`（购买资源）、
  两个钱包（记忆点数 `MP` = 失败货币 / 守护点数 `PP` = 成功货币）。
- **购买是自动的**：全局最便宜优先，每 tick 反复买到买不起。这是数值基准的一部分，没有手动购买
  （手动会改购买顺序 → 改结果）。角色页里的升级表是**只读状态面板**。
- **每层 8 项升级**，共 32 项：生产Ⅰ–Ⅳ / 资源转化Ⅰ–Ⅳ（249）、生产Ⅰ–Ⅳ / 全体效率Ⅰ–Ⅳ（耶维奇）、
  单次削减Ⅰ–Ⅳ / 削减回收Ⅰ–Ⅳ（白琦）、削减频率Ⅰ–Ⅳ / 敌方转化Ⅰ–Ⅳ（恒）。
- **两项永久**：覆灭结算买 `F1..F4`（记忆库 / 人情账 / 手感 / 长跑），守护结算买 `U1..U4`（守护印记）。
  两种货币互不兑换，只买本次事件所属层，余额跨层保留。
- **每角色两个科技**：① 自动购买（数值基准恒开，无需购买，不影响结果）② 该层的失败永久 `F_s`。
- **科技树保留但不解锁**（本轮不做）。
- **时间结构**：单轮 = 一次开店到覆灭/守护；整程 = 从第一层连续推进到第四层成功（`F4` 用整程时间）。

## 被移除的旧机制（V5 里没有对应）

万事屋兑换（mtc→MP/PP）、手动长按生产、批量购买 / 买最多 / 每 10 级涨价、每角色 4 科技、
每角色 9 节点科技树 + 通用树 + 觉醒点 AP、白琦的暴击/龙层/斩杀、恒的爆发/α、249 的速度与起始产量、
耶维奇的双向互转与深渊减速、成就数值加成、旧的三资源永久体系。
