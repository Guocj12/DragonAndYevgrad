# dny — 龙与耶维城 · 八层 + 终局

八层对抗式增量放置游戏（反物质维度式的多层重置）。玩家在耶维城经营奶茶店，用奶茶净化深渊；
深渊的压迫一旦追平你的净化力，耶维城覆灭、一切回到档 0；净化力打穿本档的深渊总量，就是「守护」，
视野外扩一档并结算一份守护点数。八层全部打穿后进入**终局**：终局永远不判成功，压力追上你时才结束一轮。

**本版覆盖第一层到第八层 + 终局。**

前端套的是 **反物质维度（AD）的壳**：AD 的 `styles.css` / `old-ui.css`、字体与图标、
`o-primary-btn` / `o-tab-btn` 这套类名约定 + Vue 2 运行时。

## 数值的权威在哪

> **`docs/数值设计.md`（V8）是唯一权威。**
> 代码里 `src/v8.js` 是它的 **逐句移植**（§14 完整独立模拟器），含运算顺序、`Math.expm1` / `Math.log1p`
> 的调用位置；一个数都不许改。`src/engine.js` 只是外壳（tick 调度、结算接线、存读档、剧情、面板），
> 不参与任何数值计算。

参考物不手抄：`tools/extract-reference.mjs` 把文档 §14 那段 javascript 原样抽成
`tools/v8-reference.cjs`，文档改了就重抽。

## 玩法要点（全部由 20Hz 结算自动跑）

- **四个量**：净化力（工作坐标 `x` → 真实量 `F=Phi_s(x)`）、深渊压力 `h`、
  购买资源 `R`（显示名 mtc，**随档乘数后四舍五入成整数**：第 1 层 ×10，2.2 → 22 mtc；第 L ≥ 2 层 ×10^(L+1)，让各层开局的门票/收入是 2X 起的整数）、
  两个钱包（记忆点数 `MP` = 失败货币 / 守护点数 `PP` = 成功货币）。
- **数字显示**：真实量用科学计数法，指数写完整十进制（八层最大到 `2.49e2492094949`）。
  任何地方都不出现 `e-1` 这种负指数（<1 显示成小数 `0.05`）。
- **购买**：手动点单项，或按「一键买满」（= 只把**当前角色**的 8 项按最便宜优先买到买不起，不碰其他角色）。
  一至四层逐级买（保持开局浮点路径），五层起走等价批量（阈值二分 + 逐级尾部）。
- **64 项临时升级**：每层 8 项，每个角色页只显示**该角色自己的 8 项**；进入更高层后旧层 8 项
  按旧门槛自动重买（等级按密度 `k=8·10^(l-o)` 放大，能到上亿级），界面不单独展示。
- **科技页**：每个角色两项 —— 自动购买 + 该角色专属永久升级（MP 购买）。
  - 「自动购买」**默认 0 级 = 完全不自动**；升到 1 级起才按间隔自动买本层升级项。
  - 「专属永久升级」**结算不再默认替玩家花钱**：覆灭/守护只发币，钱留在钱包里。
    想自动花，要么在科技树买「自动化中枢」Lv1（这一级同时自动买全角色科技与专属永久升级），
    要么在科技页点「手动升级」。
- **科技树**（只有 249 页有这一页，vis-network 中心辐射图，共 85 个节点）：
  - **中心 = 自动化中枢**（13 级，PP）。价格：前 7 级各 **2 PP**，之后每级 ×2（Lv8=4 … Lv13=128）。
    等级效果依次为：① 自动购买全角色科技 → ② 自动覆灭结算 → ③ 自动守护结算 →
    ④ 自动买「净化效率」→ ⑤ 自动买「伤害效率」→ ⑥ 自动买「MP 倍率」→ ⑦ 自动买「PP 倍率」；
    8–12 级每级把购买间隔 ×0.7943（与「科技」里的自动购买同一常量），13 级满级 **0.05 秒一次（每秒 20 次）**。
  - **主干 = 四项成功科技**：净化效率（MP）/ 伤害效率（MD）/ MP 倍率（MF）/ PP 倍率（MS）
    —— 等级就是 `permanent.success`，守护结算时用 PP 自动买；手动点节点也能买，但**要先买中枢**
    （前置约束只作用于手动点击，自动结算按数值文档照常进行）。
  - **叶子（8 个）**：保留旧节点名与位置，**效果为空、价格 0**，前置是先买对应主干；测试不买。
  - **角色节点（8 角色 × 9）**：AP 解锁结构复原，颜色按角色区分，但**效果为空、不可购买**。
- **八种失败永久** n1..n8（MP）：覆灭只买**事件所属层**那一项，余额跨层保留。
- **机制**：五层同步（只补弱侧）、六层蓄能（生产充能 + 10 秒冷却一次全释放）、
  七层缓冲（触碰失败线时只吸收本 tick 新增压力）、八层侵蚀（削弱压力增长，疲劳随侵蚀累积）。
- **自动覆灭 / 自动守护默认都关**：覆灭或守护都会弹窗，点「覆灭结算 / 净化结算」才继续（设置页可打开自动）。
- **终局**：八层全守护后进入终局，跨标线不发奖励、不停机；压力追上的那次覆灭才结束本轮并回第一层。
