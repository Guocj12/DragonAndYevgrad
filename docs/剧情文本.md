# 游戏内剧情文本 · 触发时机

> **原则**：每一条只由游玩进度触发，没有任何一条挂在「时间到了」上。
>
> 四类事件触发：**进店**（首次进入 / 每次覆灭后重开）、**覆灭**、**守护**、**通关**。
> 一类状态触发：**到达某档**（只播一次）。
>
> 事件触发在结算那一刻排队播放，播放时游戏暂停，点完继续。
> 状态触发每 0.5 秒查一次进度，满足且没播过就播，播完才查下一条。
>
> 本节所有文本为作者定稿，下面的表只负责说明「什么时候播」。

## 二、文本稿

> 每行是一段（点一次前进一段）。`/` 是段内换行。
> 以 `（旁白）` 起头的段没有说话人；以角色名起头的段显示名字。

### 三条自检

1. **双禁**：前四层只以旁白出现；`shuangjin-line` 是她第一次有实体台词，并且在同一段里自己交代「前面那些话，也是我念的」。
2. **只有玩家看得见她**：只用 249 的「今日无新增访客记录 / 您在跟谁说话？」侧写，不解释、不点破。
3. **XyT**：只有一句台词，就是它自己的名字；介绍由双禁说，恒只补一句「它在刻字」。

> 前四层的 `baiqi-found` / `heng-found` 仍是「守护了飞龙国 / 奶茶大陆」的错位一格写法（见第五节第 1 条），后四层没有沿用这个错位：`xixi-found` 说的「整颗星球清空了」正对第 5 层。
