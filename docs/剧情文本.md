# 游戏内剧情文本 · 触发时机

> **原则**：每一条只由游玩进度触发，没有任何一条挂在「时间到了」上。
>
> 四类事件触发：**进店**（首次进入 / 每次覆灭后重开）、**覆灭**、**守护**、**通关**。
> 一类状态触发：**到达某档**（只播一次）。
>
> 事件触发在结算那一刻排队播放，播放时游戏暂停，点完继续。
> 状态触发每 0.5 秒查一次进度，满足且没播过就播，播完才查下一条。
>
> 本节所有文本为作者定稿，下面的表只负责说明「什么时候播」。

## 四、两条「第 N 次及以后」怎么区分第一次

`baiqi-again` 和 `heng-again` 要「第二次及以后到达该档才播」，第一次不播。实现方式是 `onlyIfSeen`：

| 条目 | 触发 | 含义 |
|---|---|---|
| `baiqi-line` | 首次到达档 2（只播一次） | 第一次到达时播完整登场 |
| `baiqi-again` | 守护档 1 成功（进档 2）+ **看过 `baiqi-line` 才播** | 第一次跳过，第二次起每次播 |

`heng-again` 同理，依赖 `heng-line`。
