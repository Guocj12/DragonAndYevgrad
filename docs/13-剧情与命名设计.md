## 二、设计原话里已经确定的设定（不再改动）

来源：`docs/00-原始设计-用户原话.md`、`docs/10-设计文档.md`。

- 玩家在耶维城经营一家奶茶店；耶维城面临被深渊势力侵蚀的危机，奶茶可以净化深渊力量。
- 深渊成指数增长，满则耶维城覆灭；奶茶把深渊清零则守护了耶维城，上限提高一档。
- **249**：奶茶店的超级人工智能，开局即解锁，全自动生产奶茶；不会记得每次轮回，但数据库里有每一轮的记录；
  拥有这个世界的知识库，会向玩家介绍各种操作玩法。
- **耶维奇**：第一次提高上限时解锁，男性，万事屋店主；可独立生产奶茶，也会为其他角色提供强力辅助。
- **白琦**：第二次提高上限时解锁，使用重剑的白发屠龙少女，与耶维奇是挚友，有龙的血脉但不自知；
  可不断对深渊造成基于自身战力的伤害。
- **恒**：第三次提高上限时解锁，受深渊诅咒者，少年骑士，使用骨钉；力量与深渊同源且不会受深渊侵蚀；
  参考空洞骑士的小骑士。
- **双禁**：暂不提供解锁，只有设定。打破第四面墙的观察者，立场绝对中立且随机，乐子驱动的观察者和实验者；
  暂不出场。开场白的故事介绍其实是双禁说的，只显示文本、不显示名字。形象为魅魔（游戏中只有文字）。
- 除玩家与双禁外，其他角色都没有每次轮回之间的记忆。
  **补充（2026-10-23）：脑子不记得，身体记得**——肌肉、习惯、直觉跨轮保留；
  白琦的战斗技巧每轮更熟练，且没人教过她。详见 `14-故事大纲.md` §三。
- 剧情为轻剧情驱动：一种全屏黑底白字（如刚进入游戏的故事梗概），一种屏幕下方 1/3（遇到新角色时的对话、角色名），
  点击继续；文本必须数据驱动。

## 三、剧情表（已上线 6 条）

| id | 触发 | 模式 | 说话人 | 内容 |
|---|---|---|---|---|
| `intro` | 进店 + 每次覆灭重开（`repeat`） | 全屏 | —（旁白） | 5 段开场 |
| `249-intro` | 紧接着开场 | 底部 | 旁白 + 249 | 249 自我介绍与教学 |
| `first-restart` | 第 1 次覆灭后的重开 | 底部 | 249 | 发现「记忆点数」（只播一次） |
| `collapse` | 每次覆灭（`repeat`） | 全屏 | —（旁白） | 「深渊吞噬了耶维城」 |
| `first-guard` | 档 0 首次守护 | 全屏 | —（旁白） | 战后播报 |
| `yewei-join` | 同上 | 底部 | 耶维奇 | 耶维奇登场（4 句） |

填写规则（加新剧情只改 `src/story.js`，不动代码）：

```js
{
  id: '唯一 id',
  trigger: { type: 'guard', tier: 1, count: 1 },   // 或 cond / firstRun / collapse / win
  mode: 'bottom',                                   // 'fullscreen' | 'bottom'
  speaker: '耶维奇',                                 // 仅 bottom 用；不显示名字的旁白就不填
  title: '章节名',                                   // 仅 fullscreen 用，可选
  lines: ['第一段', '第二段'],                        // 点击继续，最后一段点完自动消失
}
```

条件型可用字段：`tier / mtc / cycles / guards / time / ap / prog / upgrade / tech / node / tree`，
组合用 `{ all: [...] }` / `{ any: [...] }`。
