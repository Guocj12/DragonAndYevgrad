## 格式约定（作者定）

| 记号 | 含义 |
|---|---|
| 每个换行 | 一段（点击一次前进一段） |
| `/` | 段内换行（同一屏里的第二行） |
| `（）` 开头 | 这一段没有 speaker，是旁白；仍处在底部对话里 |
| `角色：` 开头 | 底部对话（bottom），左上角显示角色名 |
| 没有角色名、也没有冒号 | 全屏（fullscreen） |

## 八、风格口径（从这批文本提炼，后续所有文案照此写）

1. **旁白是说明书**：陈述句，一句一个信息点；不抒情、不用第一人称、不堆形容词、不写比喻。
2. **对玩家用「你」**。
   报数据精确，不解释情绪。
4. **标点**：省略号一律 `...`；不用感叹号；破折号少用；一条台词 10–30 字。
5. **底部对话一次不超过 6 句**；一句一个动作或一个信息。
6. **不写「深渊像……」**，写「深渊会……」——用行为代替比喻。
7. 引用系统字段时单独占一行，前后不加引号以外的东西（见五的第二句）。
