# 15 — 剧情文本（作者稿）

> 本文件是**文本稿**，不是游戏数据。全稿齐了以后统一写进 `src/story.js`。
> 现行游戏里 `STORY` 仍为空表。

---

## 格式约定（作者定）

| 记号 | 含义 |
|---|---|
| 每个换行 | 一段（点击一次前进一段） |
| `/` | 段内换行（同一屏里的第二行） |
| `（）` 开头 | 这一段没有 speaker，是旁白；仍处在底部对话里 |
| `角色：` 开头 | 底部对话（bottom），左上角显示角色名 |
| 没有角色名、也没有冒号 | 全屏（fullscreen） |

## 一、开场

- **触发**：第一次进入游戏；**每次覆灭后重开时也播**
- **模式**：fullscreen

```
你在耶维城经营着一家奶茶店
耶维城面临被深渊吞噬的危机/深渊会污染人的神智，把人变成怪物
这种可怖的物质还会加速自我增殖，不断扩张
但你的奶茶可以净化深渊，使人恢复神智
尽可能多的生产奶茶，守住耶维城
```

## 四、第一次净化（档 0 首次守护）

- **触发**：档 0 首次守护结算后
- **模式**：fullscreen（前四段），然后接底部对话（耶维奇登场）

```
经过你和249的努力，城内的深渊被完全清除了
耶维城的居民在尽力进行战后重建/你结识了城内经营万事屋的店主 耶维奇
城内的危机解除，但城外仍旧遍布深渊势力
若不及时解决，深渊仍旧会反扑
```

耶维奇：我也来搭把手吧/处理城外的深渊也算在万事屋的业务范围内嘛

## 五、第一次覆灭后的追加对话

- **触发**：**只在第 1 次覆灭后**（第 2 次起不再追加）
- **播放顺序**：三（覆灭）→ 重开 → 一（开场）→ 二（249 教学）→ 五（本段）
- **模式**：bottom

```
249：这里还有...记忆点数
249：好像可以用来提升一些科技
249：为什么记忆库中有内容，但我却没有一点印象
249：店长有什么头绪吗
249：不管了，还是先继续生产奶茶要紧
```

*注：这一段同时是「记忆点数（MP）」首次向玩家揭示的地方——在此之前玩家没有 MP，也不需要知道它。*

## 八、风格口径（从这批文本提炼，后续所有文案照此写）

1. **旁白是说明书**：陈述句，一句一个信息点；不抒情、不用第一人称、不堆形容词、不写比喻。
2. **对玩家用「你」**。
3. **249 是店员**：礼貌、轻快、句尾可带「~」；解释不了的东西会卡顿（`...`），会自己把话删掉；
   报数据精确，不解释情绪。
4. **标点**：省略号一律 `...`；不用感叹号；破折号少用；一条台词 10–30 字。
5. **底部对话一次不超过 6 句**；一句一个动作或一个信息。
6. **不写「深渊像……」**，写「深渊会……」——用行为代替比喻。
7. 引用系统字段时单独占一行，前后不加引号以外的东西（见五的第二句）。
