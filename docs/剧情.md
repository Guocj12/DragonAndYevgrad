# 龙与耶维城 · 剧情与人物

> **一句话**：你在一家奶茶店当店长。你每擦亮一块地方，就看见更大的黑。
>
> **主题句**：深渊不是敌人，是「没有」。它一直都在。你做奶茶，只是为了让身边这一小块地方，暂时是「有」。

---

## 一、世界观

### 1.1 深渊

深渊是「没有」本身。它可以被理解成抽象势力，也可以具象成黑泥与怪物。它只做三件事：

1. **增殖**：加速自我增殖，不断向外扩张，吞掉一切。
2. **污染**：污染人的神智，把人变成怪物。
3. **吞噬**：被它漫过的一切不是死了，是**从未存在**。

第三条是全作的地基。覆灭之后，玩家丢掉的不是资源，是「攒过资源」这件事本身。

深渊的总量是宇宙级别的，一直都在。玩家能净化的永远只是当前视野内的一层。

### 1.2 奶茶

奶茶可以净化深渊，使被污染的人恢复神智。这是城里唯一还起作用的对抗手段。

它不杀死深渊，它把被深渊拿走的人还回来。

原理：深渊吃不掉「被认真做出来的东西」。糖、奶、茶、冰，四样有温度的材料加一份手艺，构成它无法消解的「有过」。净化就是把奶茶倒进深渊，一杯一杯把「没有」换回「存在」。

### 1.3 耶维城

每次重置的起点，也是全作唯一反复出现的地点。玩家在这里经营奶茶店，身份是**店长**。

城是「有」的最后一块地盘——至少在玩家还没抬头之前，是这样。

### 1.4 揭示结构

深渊从来没有被推走。你只是净化完眼前这一层，才终于看见外面还有多少。

| 档 | 你净化了什么 | 你随即看见什么 |
|---|---|---|
| 0 | 城内 | 城外也全是黑的 |
| 1 | 城外 | 整片大陆也全是黑的 |
| 2 | 大陆 | 大陆之外、海的那边、天的那边，也全是黑的 |
| 3 | 大陆之外 | 天上也是黑的（本版到此为止） |
| 4–7 | 星球 / 星系 / 宇宙 / 宇宙之外 | 一层比一层大，最后发现「外面」根本不存在 |

这个结构的情绪不是「我把它推远了」，是「原来一直都是这样」。

**每次守护之后，胜利感必须立刻被下一个镜头打断**：玩家抬头，看见更大的一片黑。这是全作最重要的节奏，每一档都要用一次。

### 1.5 档 = 视野

档不是更难的一关，是更大的世界。深渊没有变强，是你的视野变大了。

## 二、时间与记忆

### 2.1 三层时间

```
单轮 run    : 开店 ─────────────► 覆灭 / 守护        （几分钟到几十分钟）
轮回 cycle  : 覆灭 ──► 一切回到初始 ──► 再开一次      （时间向前，不回溯）
档位 tier   : 守护 ──► 视野外扩 + 解锁一个角色        （全流程 9–15 小时）
```

### 2.2 轮回

**覆灭 = 耶维城、奶茶店、所有角色，全部变回最初始的状态。**

时间继续向前，不回溯。玩家回到店里，城、店、人都和第一天一样。

| 对象 | 覆灭后 |
|---|---|
| 耶维城 / 奶茶店 | 回到初始状态 |
| 耶维奇 / 白琦 / 恒 | 回到初始状态（身体经验保留，见 2.4） |
| 所有升级 | 清零 |
| 玩家的记忆 | **保留。只有玩家保留** |
| 双禁 | 保留 |

### 2.3 三层记忆

| 层 | 谁有 | 内容 | 覆灭后 |
|---|---|---|---|
| **记忆** | 玩家、双禁 | 完整经历 | 保留 |
| **记录** | 249 | 店里的数据 | 保留（她本身不记得） |
| **身体** | 所有角色 | 肌肉、习惯、直觉 | 保留 |

除玩家与双禁，没有任何角色记得上一轮。

### 2.4 身体记得，脑子不记得

角色想不起任何事，但身体会重复上一轮的选择。

表现方式只有四种：

- 坐同一个位置
- 用同一只手拿杯
- 说同一句开场白
- 在同一个瞬间抬头

**白琦最明显**：她的战斗技巧每一轮都在变熟练。第一次握剑就已经会用，越打越准、越省力，她自己说不清什么时候学的。

**恒**的身体比脑子更早知道危险：深渊还没动，他已经侧身了。

**耶维奇**的身体记得店：他每次都坐同一个位置、点同一杯（他不承认自己点过）。

### 2.5 为什么这件事重要

它是玩家唯一的安慰：他们忘了你，但他们没有变成别人。

也是玩家唯一的恐惧：如果连身体都不记得了，那他们就真的只是每一轮的新人。

## 三、主线

四档，每档一个战场尺度、一个新角色、四幕、一种情绪、一盆冷水。

### 序章

玩家推门进店。开场旁白讲清城、深渊、奶茶，埋一句「外面还有」，最后落到开机。

249 上线，喊一声「店长」。

### 第一档 · 奶茶店

- **战场**：耶维城城内。深渊从下水道、招牌背面、巷子尽头渗出来。
- **目标**：净化整座城。
- **在场**：玩家、249。
- **四幕**：
  1. **开店**：一张台子，一台机器，一个人。城还在，城里已经没什么人了。
  2. **第一次覆灭**：城被抹平。玩家第一次知道「重来」是什么意思——不是死，是没有过。而三个还没登场的人，此刻正在城里过着各自的日子。
  3. **反复**：一次一次重开。店一次比一次撑得久，玩家一次比一次更清楚自己一个人在做这件事。
  4. **净化全城**：第一次「守护」。城亮起来了——玩家抬头，看见城外也是黑的。
- **情绪**：孤独。
- **冷水**：城外也全是黑的。

### 第二档 · 耶维城

- **战场**：城外的原野、公路、废墟。
- **目标**：净化城外。
- **新角色**：耶维奇（万事屋店主，城里的老生意人）。
- **四幕**：
  1. **上门**：万事屋来谈生意。他把「拯救世界」拆成一单活、一份抽成、一本账。
  2. **分工**：他开产线、找人脉、跑外场；玩家在店里做奶茶。
  3. **第一次推进与第一次覆灭**：两人一起推到城外，然后一起被抹平。
  4. **重来**：玩家回到店里，耶维奇推门进来，第一句话和第一次一模一样——**他不认识你**。但他还是坐了同一个位置。
- **情绪**：第一次有人一起，紧接着第一次失去。全作第一个真正的痛点。
- **冷水**：城外清了，地平线后面是整片大陆的黑。

### 第三档 · 飞龙国

- **战场**：整片大陆。
- **目标**：净化大陆。
- **新角色**：白琦（战场上捡到的、战斗到濒死的白发少女）。
- **四幕**：
  1. **捡到**：在战场尽头发现她。她还握着剑，剑还在响。
  2. **醒来**：她不解释、不道谢、不说话。伤好一点就开始砍。
  3. **旧识**：她和耶维奇是旧识——两人都不记得，但都下意识信任对方。
  4. **净化大陆**：一路砍到大陆边缘。龙血伏笔：剑会回应深渊里的东西，她自己没察觉。
- **情绪**：第一次有人替你挡。
- **冷水**：大陆清了，海的那边、天的那边，全是黑的。

### 第四档 · 奶茶大陆

- **战场**：大陆边缘与大陆之外。
- **目标**：净化大陆之外（本版最后一档）。
- **新角色**：恒（在大陆另一端、深渊里沉睡的少年骑士）。
- **四幕**：
  1. **找到**：大陆另一端，深渊绕着一个人流，不敢碰他。他睡着，骨钉插在身旁。
  2. **唤醒**：他醒来，不记得自己是谁，只知道自己和深渊同源。
  3. **同处**：四个人第一次在同一间店里。三张椅子，一台机器。
  4. **长跑**：几十上百次覆灭。全作时间最长的一段，叙事上靠「每几次覆灭一条短剧情」当节拍器。
- **情绪**：家。
- **本版结尾**：净化大陆之外。四人站在原地，抬头——**天上也是黑的**。游戏到此为止。

### 终局（本版）

不揭真相，不做结局。只做一件事：抬头。

## 四、人物

### 4.1 249 · 奶茶店人工智能

- **一句话**：记得这店里发生过的所有事，唯独不记得你。
- **身份**：开局即在岗的店员型人工智能，女性声线，负责全自动生产奶茶。
- **核心矛盾**：她的记忆库里有每一轮的数据，她本身却没有记忆。她能说出你上一轮做了什么，但每次都要重新认识你。**她的温柔和她的残忍是同一种东西：她把你写进库里。**
- **表层**：店员式的礼貌——「店长您回来了~」、报产量、报库存、报城内情况。语气轻快，句尾常带「~」；遇到解释不了的东西会卡顿（「...」）。
- **里层**：她在「选择记什么」。她加密的条目、她删了又出现的记录、她念不出口的字段——这些是她全部的情感表达，她自己不承认那是情感。
- **身体记得什么**：她没有身体。她的「身体记忆」是记忆库的结构——有些字段她会不自觉地保留（一条删了又出现的异常记录、一个没有来源的条目名）。
- **成长曲线**：记录**数据**（产量、库存、城内情况）→ 记录**人**（谁在什么时间做了什么）→ 记录**异常**（「记忆库中有内容，但我却没有一点印象」这类她自己解释不了的东西）。
- **弱点**：无法理解「没被记录的东西」。所以她无法理解玩家为什么难过。
- **关系**：与耶维奇斗嘴（数据 vs 账本）；对白琦做伤情监测；对恒把「记忆库异常」念出来。
- **台词规则**：礼貌、轻快、句尾可带「~」；报数据时精确；遇到解释不了的东西会卡顿、会自己删掉；不用形容词，不直接表达情绪。**她的情感只能从「她记录了什么、删掉了什么」里读出来。**
- **名字**：249 是编号。她没有解释过这个编号，也没人问过。

### 4.2 耶维奇 · 万事屋店主

- **一句话**：把世界末日当生意做的男人，因为他只会这个。
- **身份**：城内万事屋店主，什么活都接。第一次提高上限时入伙，能独立生产奶茶，也为其他角色提供强力辅助。
- **核心矛盾**：他嘴上算抽成、谈欠账，实际上从来没离开过。**他用账本掩盖恐惧。**
- **表层**：市侩、抬价再降价、人脉、抽成、欠人情。抬价是试探，降价是真心。
- **里层**：他怕的不是死，是**白干**。所以他要把每件事都记成账——账能证明他做过。
- **身体记得什么**：每次开工都坐同一个位置、点同一杯（他不承认自己点过）、习惯用左手扶杯、说同一句开场白。他自己解释为「老习惯」。
- **成长曲线**：接活 → 入伙 → 替人挡账 → 话事人。他的强不是战力，是**把四个人凑在一张桌子上**。
- **弱点**：不肯承认自己在意什么。所有情感表达必须绕道钱。对玩家从「老板」叫到「合伙人」。
- **关系**：与白琦是旧识（重逢即初遇，但两人都下意识信任对方）；与 249 斗嘴；是恒唯一会坐过去的人。
- **台词规则**：短句、实在，只谈活、人、账；不抒情、不比喻；抬价再降价是他的试探方式；情绪只出现在「他记的那一笔账」上。
- **与城同源**：「耶维奇」与「耶维城」共用一个词根。他从没解释过，也没人问过。

### 4.3 白琦 · 屠龙少女

- **一句话**：一把还在响的剑，和一个不知道自己为什么会使剑的人。
- **身份**：白发，重剑，在战场上被捡到。第二次提高上限时入伙，每秒对深渊造成一次伤害。
- **核心矛盾**：她砍的东西和她的血同源。她越强，越接近「自己也是深渊的一部分」。**她越熟练，越不像人。**
- **表层**：寡言、行动派、「我砍它，你负责别死」。不解释、不道谢、不求助。
- **里层**：她其实一直在找同类。龙血在找龙；剑在找深渊。她的「强」是召唤，不是杀意。
- **身体记得什么**：战斗技巧每一轮都在长进。第一次握剑就已经会用，越打越准、越省力；她自己说不清什么时候学的。**这是全作「身体记忆」最外显的一条线**，也是龙血真相的伏笔：不是她在练剑，是剑在教她。
- **成长曲线**：濒死被捡到 → 恢复 → 熟练 → 剑会自己找弱点 → 龙血显形（剑身发亮，她自己看不见）→ 能听见深渊「说话」。
- **弱点**：不会求助。伤没好就上。她所有的伤都是自己扛的。
- **关系**：与耶维奇是旧识；对玩家是「你负责别死」；与恒有同类的直觉（龙血 vs 深渊）。
- **台词规则**：一句不超过 20 字，动宾结构，不解释。她的话越少，分量越重。

### 4.4 恒 · 少年骑士

- **一句话**：深渊吃不掉的人，世界也记不住。
- **身份**：在深渊里沉睡的少年骑士，骨钉为武器。第三次提高上限时入伙。战力随深渊强弱变化——深渊越强他越强。
- **核心矛盾**：他与深渊同源，所以不会被侵蚀；也正因为同源，他不会被「深渊之外的东西」记住。**他唯一想要的不是胜利，是被记住。**
- **表层**：沉默、顺从、「我不知道」。很少用「我」开头。
- **里层**：极强的执念——他想留下痕迹。他会在意一些很小的东西（一个名字、一句话、一个位置）。
- **身体记得什么**：身体比脑子更早知道危险——深渊还没动，他已经侧身了。骨钉会自己呼应深渊的节奏（他以为是心跳）。
- **成长曲线**：沉睡 → 唤醒（不记得自己是谁）→ 结伴 → 第一次被叫名字 → 长跑中逐渐「有存在感」（他的战力随深渊增长，但他的存在感随玩家增长）。
- **弱点**：他会吸收深渊力量，吸太多会失控。
- **关系**：与玩家最亲（玩家是唯一记得他的人）；对白琦有同类直觉；对耶维奇几乎不说话，但会坐他旁边。
- **台词规则**：比白琦更短，常用「我不知道」，很少用「我」开头。**他的变化只能靠同一句台词逐字变长来表现。**

### 4.5 双禁 · 观察者

- **一句话**：她知道一切，也包括你这次会不会赢。
- **身份**：这款游戏的设计者本人。她知道轮回、结局、玩家的每一次重来。下场只是为了好玩。形象为魅魔（游戏中只有文字）。
- **立场**：绝对中立，乐子驱动。帮不帮只看这样是否有趣。
- **叙事位置**：只出现在**全屏旁白**里，**从不署名**。语气是第一人称，慵懒、戏谑、危险。
- **和玩家的关系**：她是唯一能和玩家「平等对话」的存在（两个人都记得一切），但她不会。**这比「没人记得你」更孤独**：有人记得，但她不打算陪你。
- **她可能做的小动作**：给玩家一个「偶然」、改一个数字、让某件事差一点发生。玩家能感觉到，但无法证明。
- **露面的时机**：开场、第一次揭示之后、终局。共三次。

### 4.6 玩家 · 耶维城奶茶店店长

- **身份**：耶维城的奶茶店店长。没有名字，没有台词，永远第一人称沉默。
- **特殊性**：唯一记得每一轮的人。
- **弧线**：守住店 → 守住人 → 为了让他们再出现一次。
- **写文本时的处理**：玩家永远不发言。所有对玩家的回应都用侧写（例：「你说了什么。她没有记下来。」——这类侧写是全作唯一能写「玩家」的地方）。

### 4.7 四件永不重置的东西

每个角色都有一件自己带来的、覆灭也带不走的东西。它就是这个人的灵魂，也是「身体记得」唯一的物证：

| 角色 | 永不重置的东西 | 是什么 |
|---|---|---|
| 249 | **记忆库** | 她记下的每一轮数据。她不记得你，但她记着你做过的事。 |
| 耶维奇 | **人情账** | 他记的账。账能证明他干过活，也能证明他欠过谁。 |
| 白琦 | **手感** | 她越打越熟的剑。没人教过她。 |
| 恒 | **长跑** | 他能一直走下去这件事本身。 |

守护过的每一层，也会留下一枚印记：**城内 / 城外 / 大陆 / 大陆之外**。四枚印记连起来，就是玩家亲眼看过的那四层黑。

## 五、场景表

> `F` = 全屏旁白（双禁在场时不署名）；`B` = 底部对话。
> 「这一幕要完成什么」是唯一约束，台词由作者写。

### 序章

| # | 场景 | 形式 | 谁 | 这一幕要完成 |
|---|---|---|---|---|
| 1 | 首次进店 | F | 不署名 | 讲清城、深渊、奶茶；埋一句「外面还有」；落到「开机」 |
| 2 | 开机 | B | 249 | 喊一声店长；一句说明她能自动生产 |

## 七、写作口径

1. **旁白是说明书**：陈述句，一句一个信息点；不抒情、不用第一人称、不堆形容词、不写比喻。
2. **对玩家用「你」**。报数据精确，不解释情绪。
3. **标点**：省略号一律 `...`；不用感叹号；破折号少用；一条台词 10–30 字。
4. **底部对话一次不超过 6 句**，一句一个动作或一个信息。
5. **不写「深渊像……」，写「深渊会……」**——用行为代替比喻。
6. **玩家永远没有台词**。所有对玩家的回应都用侧写；侧写是全作唯一能写「玩家」的地方。
7. **除玩家与双禁，没有任何角色记得上一轮**。任何「我们是不是见过」都必须被角色自己否定，或者只以身体习惯出现。
8. **每次守护之后必须立刻浇一盆冷水**：玩家抬头，看见更大的一片黑。
9. **双禁不署名**。她只出现在全屏旁白里，语气能认出她，名字永远不出现。她的辨识度不靠形容词，靠句式：无主旁白说陈述句，她说第二人称、预告、带立场的话。
10. **每个设定只说一次**。说两遍就是没设计。

## 八、结局与远景

> 本节只做世界观，不做任何游戏内容。本版游戏到「抬头看见天上也是黑的」为止。

### 8.1 结局结构

| 类型 | 触发 | 内容 |
|---|---|---|
| 全局好结局 | 最终区域 净化 | 深渊被真正意义上净化 |
| 全局坏结局 | 最终区域 覆灭 | 深渊吞噬一切，在此揭露深渊真相 |

每解锁一个结局，获得一个强力永久加成，然后一切完全从头开始。一周目不可能打到好结局：必须靠其他结局的加成累积，才有机会去打真正的净化。

### 8.2 双禁在结局里的位置

她知道每一个结局、每一个周目。她看着玩家一次次重来。她的出场方式取决于哪个结局更「好看」——这是她的立场，不是恶意。

### 8.3 深渊真相（三选一，未定）

- **A 熵**：深渊是「没有」本身，是宇宙的底色。玩家在做的不是拯救，是抵抗熵。
- **B 残渣**（推荐）：深渊是被清零的上一周目。每次结局重置，玩家删掉的一切并没有消失，它们堆在宇宙外面，变成了深渊。**你打的每一只怪，都是你自己删掉的东西。**
- **C 实验**：深渊是双禁的实验废料——她玩坏过很多个周目，那些周目的残骸就是深渊。

> B 与「结局清零、一切重来」严丝合缝，还能给好结局一个真正有力的落点：玩家要净化的不是外面的黑，是自己删掉的东西。

### 8.4 档 4–7（不实现）

| 档 | 战场 | 玩家会看见什么 |
|---|---|---|
| 4 | 星球 | 大陆之外还有整颗星球，星球上早没有活物 |
| 5 | 星系 | 星球只是一粒；星系里的深渊密度超乎想象 |
| 6 | 宇宙 | 整个宇宙的底色是黑的——「星空」是深渊没吃干净的地方 |
| 7 | 宇宙之外 | 外面也是深渊。深渊的真相在此揭晓 |

最终揭示：**没有「外面」。** 只有玩家脚下这一小块「有过」，和它周围无限大的「没有」。
