# 龙与耶维城 · 剧情与人物

> **一句话**：你在一家奶茶店当店长。你每擦亮一块地方，就看见更大的黑。
>
> **主题句**：深渊不是敌人，是「没有」。它一直都在。你做奶茶，只是为了让身边这一小块地方，暂时是「有」。
>
> 人物设定见 [人物.md](人物.md)（唯一权威）；游戏内文本与触发时机见 [剧情文本.md](剧情文本.md)。

---

## 一、世界观

### 1.1 深渊

深渊是「没有」本身。它可以被理解成抽象势力，也可以具象成黑泥与怪物。它只做三件事：

1. **增殖**：加速自我增殖，不断向外扩张，吞掉一切。
2. **污染**：污染人的神智，把人变成怪物。
3. **吞噬**：被它漫过的一切不是死了，是**从未存在**。

第三条是全作的地基。覆灭之后，玩家丢掉的不是资源，是「攒过资源」这件事本身。

深渊的总量是宇宙级别的，一直都在。玩家能净化的永远只是当前视野内的一层。

### 1.2 奶茶

奶茶可以净化深渊，使被污染的人恢复神智。这是城里唯一还起作用的对抗手段。

它不杀死深渊，它把被深渊拿走的人还回来。

原理：深渊吃不掉「被认真做出来的东西」。糖、奶、茶、冰，四样有温度的材料加一份手艺，构成它无法消解的「有过」。净化就是把奶茶倒进深渊，一杯一杯把「没有」换回「存在」。

### 1.3 耶维城

每次重置的起点，也是全作唯一反复出现的地点。玩家在这里经营奶茶店，身份是**店长**。

城是「有」的最后一块地盘。至少在玩家还没抬头之前，是这样。

### 1.4 揭示结构

深渊从来没有被推走。你只是净化完眼前这一层，才终于看见外面还有多少。

| 层 | 档名 | 你净化了什么 | 你随即看见什么 |
|---|---|---|---|
| 1 | 奶茶店 | 城内 | 城外也全是黑的 |
| 2 | 耶维城 | 城外 | 整片大陆也全是黑的 |
| 3 | 飞龙国 | 大陆 | 海的那边、天的那边，也全是黑的 |
| 4 | 奶茶大陆 | 大陆之外 | 天上也是黑的 |
| 5 | 奶盖星球 | 整颗星球 | 月亮暗面有一块不反光的黑斑 |
| 6 | 珍珠月 | 星球之外 | 星系里每一颗星都是黑的 |
| 7 | 黑糖星系 | 星系 | 宇宙的底色是黑的——星空是没被吃干净的地方 |
| 8 | 气泡宇宙 | 宇宙 | 宇宙之外也全是黑的 |
| 终局 | 深渊 | 宇宙之外（清不完） | 黑上有进度：所有宇宙在同一片外面清理 |

这个结构的情绪不是「我把它推远了」，是「原来一直都是这样」。

**每次守护之后，胜利感必须立刻被下一个镜头打断**：玩家抬头，看见更大的一片黑。这是全作最重要的节奏，每一层都要用一次。

### 1.5 层 = 视野

层不是更难的一关，是更大的世界。深渊没有变强，是你的视野变大了。

后四层用奶茶配料做卡通前缀，把尺度一路推到宇宙：奶盖星球 / 珍珠月 / 黑糖星系 / 气泡宇宙。**「深渊」这个主题词只在终局出现一次**，不铺在每一层的名字上。

## 二、时间与记忆

### 2.1 三层时间

```
单轮 run    : 开店 ─────────────► 覆灭 / 守护        （几分钟到几十分钟）
轮回 cycle  : 覆灭 ──► 一切回到初始 ──► 再开一次      （时间向前，不回溯）
层位 tier   : 守护 ──► 视野外扩 + 解锁一个角色        （全流程 9–15 小时）
```

### 2.2 轮回

**覆灭 = 耶维城、奶茶店、所有角色，全部变回最初始的状态。**

时间继续向前，不回溯。玩家回到店里，城、店、人都和第一天一样。

| 对象 | 覆灭后 |
|---|---|
| 耶维城 / 奶茶店 | 回到初始状态 |
| 八层角色 | 回到初始状态（身体经验保留，见 2.4） |
| 249 的数据库 | **保留**（她本人没有记忆，见 2.3） |
| 所有升级 | 清零 |
| 玩家的记忆 | **保留。只有玩家保留** |
| 双禁 | 保留 |

### 2.3 三层记忆

| 层 | 谁有 | 内容 | 覆灭后 |
|---|---|---|---|
| **记忆** | 玩家、双禁 | 完整经历 | 保留 |
| **记录** | 249 | 店里的数据 | 保留（她本身不记得） |
| **身体** | 所有角色 | 肌肉、习惯、直觉 | 保留 |

除玩家与双禁，没有任何角色记得上一轮。

### 2.4 身体记得，脑子不记得

角色想不起任何事，但身体会重复上一轮的选择。

表现方式只有四种：

- 坐同一个位置
- 用同一只手拿杯
- 说同一句开场白
- 在同一个瞬间抬头

**白琦最明显**：她的剑法每一轮都在长进。她知道自己有龙族血脉，但那一手越打越省力的剑，不是学来的。

**恒**的身体比脑子更早知道危险：深渊还没动，他已经侧身了。

**耶维奇**的身体记得店：他每次都坐同一个位置、点同一杯（他不承认自己点过）。

### 2.5 为什么这件事重要

它是玩家唯一的安慰：他们忘了你，但他们没有变成别人。

也是玩家唯一的恐惧：如果连身体都不记得了，那他们就真的只是每一轮的新人。

## 三、主线

八层加终局。每层一个战场尺度、一个新角色、四幕、一种情绪、一盆冷水。

### 序章

玩家推门进店。开场旁白讲清城、深渊、奶茶，埋一句「外面还有」，最后落到开机。

249 上线，喊一声「店长」。

开场旁白不是无主的旁白——它是双禁念的，读者要到第五层才知道这件事。

### 第一层 · 奶茶店（249）

- **战场**：耶维城城内。深渊从下水道、招牌背面、巷子尽头渗出来。
- **目标**：净化整座城。
- **四幕**：
  1. **开店**：一张台子，一台机器，一个人。城还在，城里已经没什么人了。
  2. **第一次覆灭**：城被抹平。玩家第一次知道「重来」是什么意思——不是死，是没有过。
  3. **反复**：一次一次重开。店一次比一次撑得久，玩家一次比一次更清楚自己一个人在做这件事。
  4. **净化全城**：第一次「守护」。城亮起来了——玩家抬头，看见城外也是黑的。
- **情绪**：孤独。
- **冷水**：城外也全是黑的。

### 第二层 · 耶维城（耶维奇）

- **战场**：城外的原野、公路、废墟。
- **目标**：净化城外。
- **四幕**：
  1. **上门**：万事屋上门搭把手。他把「拯救世界」拆成一堆能办的小活，一件一件办。
  2. **分工**：他开产线、找人脉、跑外场；玩家在店里做奶茶。
  3. **第一次一起被抹平**：两人一起推到城外，然后一起被抹平。
  4. **重来**：玩家回到店里，耶维奇推门进来，第一句话和第一次一模一样——**他不认识你**。但他还是坐了同一个位置。
- **情绪**：第一次有人一起，紧接着第一次失去。
- **冷水**：城外清了，地平线后面是整片大陆的黑。

### 第三层 · 飞龙国（白琦）

- **战场**：整片大陆。
- **目标**：净化大陆。
- **四幕**：
  1. **捡到**：战场尽头，她还握着剑，剑还在响。
  2. **醒来**：不解释、不道谢，伤好一点就开始砍。话多，直给。
  3. **旧识**：她和耶维奇认得出对方——两人都想不起在哪见过。
  4. **净化大陆**：一路砍到大陆边缘。剑会回应深渊里的东西，她自己没察觉。
- **情绪**：第一次有人替你挡。
- **冷水**：大陆清了，海的那边、天的那边，全是黑的。

### 第四层 · 奶茶大陆（恒）

- **战场**：大陆边缘与大陆之外。
- **目标**：净化大陆之外。
- **四幕**：
  1. **找到**：大陆另一端，深渊绕着一个人流，不敢碰他。他睡着，骨钉插在身旁。
  2. **唤醒**：他醒来，不记得自己是谁，只知道自己和深渊同源。
  3. **同处**：四个人第一次在同一间店里。三张椅子，一台机器。
  4. **长跑**：几十上百次覆灭。全作时间最长的一段，靠「每几次覆灭一条短剧情」当节拍器。
- **情绪**：家。
- **冷水**：净化大陆之外之后，玩家抬头——**天上也是黑的**。这是四层结尾。

### 第五层 · 奶盖星球（双禁）

- **战场**：整颗星球。深渊把星球蛀空了，蛀孔连成一条条往下的回廊。
- **目标**：清空整颗星球。
- **四幕**：
  1. **往下走**：天上也是黑的，黑不在外面，在脚下。玩家顺着回廊往下打。
  2. **她来了**：店里多了一个人，坐在窗边。只有玩家看得见她；249 报「今日无新增访客记录」。她第一次开口，并当场交代：前面那些旁白也是她念的。
  3. **调平**：她不生产、不战斗，只把两边的效率拉到同一条线上——玩家强就补深渊，深渊强就补玩家。最险的一次，她把压力压到「刚好扛得住」。
  4. **清空星球**：她一间一间把回廊的灯关掉，像验收。
- **情绪**：终于有人看见了，但那个人不站在你这边。
- **冷水**：星球干净了，抬头看月亮——月亮的暗面有一块不反光的黑斑。

### 第六层 · 珍珠月（曦曦）

- **战场**：近星轨道、卫星、整片近星空间。
- **目标**：清空星球之外。
- **四幕**：
  1. **下柜**：一直睡在收银台上方那只白猫跳下来，走到门口，回头等玩家。
  2. **她是月亮**：249 的观测记录对上了（月面亮度异常上升），白琦一句话问破。
  3. **周期**：满月亮得整片轨道发白，一次能烧穿一条路；放完要暗很久。她的强弱由周期决定，不由数量决定。
  4. **清空近星空间**：她回到收银台上继续睡，像什么都没发生。然后说了一句：我主人在外面。
- **情绪**：一直被照着，只是从来没抬头。
- **冷水**：轨道干净了，星系里每一颗星都是黑的。

### 第七层 · 黑糖星系（空喵）

- **战场**：星系边缘，一道一直围成一圈的紫黑的墙。
- **目标**：清空星系。
- **四幕**：
  1. **墙**：她把秩序一层一层铺在深渊推进的路上，压上来多少，卸掉多少。
  2. **主人**：她是给这颗星球挂灯的人，等曦曦等了很久。见面第一句是「你亮了」。
  3. **只挡这一次**：她只接得住本 tick 的新增，接不住已经压上来的总量。所以她永远被打下去，又永远站直；身上的压痕数不清。
  4. **清空星系**：墙拆下来，宇宙的底色露出来。
- **情绪**：有人一直在你身后接住你，你从没回头看过。
- **冷水**：宇宙的底色是黑的——星空只是深渊没吃干净的地方。

### 第八层 · 气泡宇宙（XyT）

- **战场**：宇宙的底。
- **目标**：清空宇宙。
- **四幕**：
  1. **一处不对**：宇宙的底有一块地方，不属于深渊，也不属于「有」。
  2. **游戏没做完**：双禁第一次说「好啦，游戏还没做完，到这里就结束啦。诶，怎么有个 bug 这样」。249 查不到这个东西。
  3. **改数**：它能直接改深渊的增长速度，不经过任何规则；代价是自己越来越像深渊。恒说，它在刻字。
  4. **清空宇宙**：它把自己刻进最后一道痕里。名字是 `XyTT2N2bTc`——`HelloWorld` 被错误编码之后的样子。
- **情绪**：你打的最后一样东西，是这个世界写错的第一句话。
- **冷水**：宇宙清空了，站在宇宙边缘往外看——外面也全是黑的。

### 终局 · 深渊

- **战场**：宇宙之外。没有边界，也没有「更外面」。
- **目标**：清不完。终局只判失败，不判成功。
- **内容**：
  1. 八层全部守护之后进入终局。跨标线不发奖励、不停机。
  2. 终局加入**全服统一清理进度**：所有宇宙的店长在清同一片外面，进度共享。你看得见每一格被清掉，看不见任何一个人。
  3. 压力追上你的那一次，本轮结束，回到第一层。店里一切如初，只有进度条上的数字还在涨。
- **情绪**：不是一个人在守，但谁也见不到谁。
- **双禁**：她在终局说最后一句（不署名）。

## 七、写作口径

1. **旁白是说明书**：陈述句，一句一个信息点；不抒情、不用第一人称、不堆形容词、不写比喻。
2. **对玩家用「你」**。报数据精确，不解释情绪。
3. **标点**：省略号一律 `...`；不用感叹号（白琦除外，她的语气就是带劲）；破折号少用；一条台词 10–30 字。
4. **底部对话一次不超过 6 句**，一句一个动作或一个信息。
5. **不写「深渊像……」，写「深渊会……」**——用行为代替比喻。
6. **玩家永远没有台词**。所有对玩家的回应都用侧写；侧写是全作唯一能写「玩家」的地方。
7. **除玩家与双禁，没有任何角色记得上一轮**。任何「我们是不是见过」都必须被角色自己否定，或者只以身体习惯出现。
8. **每次守护之后必须立刻浇一盆冷水**：玩家抬头，看见更大的一片黑。
9. **双禁的旁白用中性陈述句**（作者口吻），只有情绪溢出时才露出本人的戏谑；她第五层才现身，揭穿的不是语气，是「一直有人在念」。她的私人台词是第二人称、预告式、带立场，从不署名。
10. **每个设定只说一次**。后四层不再重复「你守护了 X」的播报，避免同一件事说两遍。

## 八、结局与远景

### 8.1 终局结构

| 项 | 内容 |
|---|---|
| 触发 | 八层全部守护 |
| 机制 | 终局永不胜，只判失败；压力追上的那一次结束本轮，回到第一层 |
| 内容 | 宇宙之外；加入全服统一清理进度，所有宇宙共同清理同一片外面 |
| 结算 | 跨标线不发奖励、不停机 |

终局的落点不是「打赢」，是「发现这不是你一个人的事」：你看得见每一格被清掉，看不见任何一个人的脸。

### 8.2 双禁在终局的位置

她知道每一个结局、每一个周目，也看着每一轮的你。终局她只说最后一句话，仍然不署名。

### 8.3 深渊真相（三选一，未定）

- **A 熵**：深渊是「没有」本身，是宇宙的底色。玩家在做的不是拯救，是抵抗熵。
- **B 残渣**（推荐）：深渊是被清零的上一周目。每次重置，玩家删掉的一切并没有消失，它们堆在宇宙外面，变成了深渊。**你打的每一只怪，都是你自己删掉的东西。**
- **C 实验**：深渊是双禁的实验废料——她玩坏过很多个周目，那些周目的残骸就是深渊。

> B 与「覆灭清零、一切重来」严丝合缝，也能给终局一个落点：玩家要净化的不是外面的黑，是自己删掉的东西。

### 8.4 九级尺度（已实现）

| 层 | 档名 | 战场 | 玩家会看见什么 |
|---|---|---|---|
| 5 | 奶盖星球 | 整颗星球 | 星球被深渊蛀空，蛀孔连成回廊；月亮暗面有黑斑 |
| 6 | 珍珠月 | 星球之外 | 卫星本体是一盏灯；星系里每颗星都黑着 |
| 7 | 黑糖星系 | 星系 | 一道紫黑的墙围在星系边缘；宇宙的底色是黑的 |
| 8 | 气泡宇宙 | 宇宙 | 宇宙的底有一处不属于深渊也不属于「有」的地方 |
| 终局 | 深渊 | 宇宙之外 | 外面也是深渊；黑上有全服共享的清理进度 |

最终揭示：**没有「外面」。** 只有玩家脚下这一小块「有过」，和它周围无限大的「没有」。
