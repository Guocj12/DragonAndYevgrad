## 二、深渊与结算

| 项 | 实现 |
|---|---|
| 地名 | 奶茶店 → 耶维城 → 飞龙国 → 奶茶大陆（界面只显示地名，不出现档号） |
| 上限 | `cap(k) = 2.49 × 10^E`，E = 249 / 2492 / 24920 / 249209 |
| 起始 | 每轮从上限的 50%（对数口径）开始；通用树「先手优势」每级把起点 ×0.9 |
| 增长 | 在对数空间做超指数：`log10 S += D·e^(t/τ)/τ·dt`，τ = 249/ln2 |
| 零产量满档 | 249 秒 |
| 结算 | 20 tick/s（dt = 0.05）；S≤0 → 守护，S≥cap → 覆灭 |
| 待结算 | 进入 `pending` 后暂停，玩家点「净化 / 覆灭结算」才生效 |
| 自动化 | 通用树中心解锁后自动结算 |

## 三、资源

| 资源 | 获取 | 用途 | 重置 |
|---|---|---|---|
| mtc | 产量累加 | 升级、万事屋兑换 | 覆灭清空 |
| MP 记忆点数 | 覆灭/守护结算；万事屋兑换 | 角色科技 | 永不重置 |
| PP 净化点 | 守护结算；万事屋兑换 | 通用树 | 永不重置 |
| AP 觉醒点 | 每档首次守护 1/2/4/8；首次覆灭 1 | 角色科技树 | 可重置返还 |

MP / PP / AP 一律整数（获取向下取整、消耗向上取整）。

## 四、升级体系

- **无等级上限**。每级成本倍率：升级 1 ×2、升级 2 ×3 …… 升级 8 ×9；基础价全部为 1。
- 每级效果 = 成本倍率的 1/8 次方（1.09 / 1.15 / 1.19 / 1.22 / 1.25 / 1.28 / 1.30 / 1.32）。
- 解锁链：前一个升级达到 10 级就开放下一个。
- 为什么是 1/8：8 项在同一个 mtc 数量级下贡献相同 → 每项贡献 `M^(1/8)`，8 项合计 `M`，与成本同阶。

**角色分工**

| 角色 | 8 项升级的构成 |
|---|---|
| 249 | 产量 ×5、净化效率 ×2、生产速度 ×1 |
| 耶维奇 | 独立产线 ×4、全体产量 ×4（不单独加强 249） |
| 白琦 | 战力增长 ×3、战力 ×3、伤害 ×2 |
| 恒 | 战力 ×3、攻速 ×2、伤害 ×2、深渊转化 ×1 |

**刚解锁时的对标**（保证新角色一解锁就能打）：

- 耶维奇 0 级：独立产线 = 249 当前产量（总产量翻倍）。
- 白琦 0 级：剑意基础存量 = 249 产量 × 10，秒伤与 249 的净化量同量级。
- 恒 0 级：战力 = 249 产量 × 10 × (1 + log10(S/S0))^(1+2α)，随深渊增长、但用对数幂次防止爆炸。

## 五、科技（除自动采购外全部无上限）

- 成本指数上升（`base × mult^等级`）。
- 自动采购：1–8 级依次解锁前 N 个升级的自动购买；9 级起购买间隔 ×0.95；**68 级满级：每秒 20 次，每次直接买到买不起**。
- 其余科技效果对等级线性，成本指数 → 玩家自然停在对性价比合适的位置。
- 耶维奇的三项：
  - **商业谈判**：降低 MP 兑换价格的增长率（下限 1.05）。
  - **渠道批发**：降低 PP 兑换价格的增长率（下限 1.05）。
  - **资源转化**：把 249 加成的一部分叠到独立产线，独立产线的一部分叠回 249（饱和函数，收敛）。

## 六、万事屋（mtc → MP / PP）

| 项 | 基础价 | 增长率 | 每次 |
|---|---|---|---|
| MP | 10 mtc | ×1.6 | +1 MP |
| PP | 25 mtc | ×2.2 | +1 PP |

价格 = `基础价 × 增长率^已兑换次数`；增长率可被商业谈判 / 渠道批发压低，下限 1.05。

---

## 七、通用科技树

13 节点：1 中心 + 4 主干 + 8 叶子。

- **自动化中枢**：初始 1 PP，每级 ×2。1–6 级依次解锁 自动覆灭 / 自动净化 / 自动买四种翻倍；
  7 级起每级把自动间隔 ×0.95，65 级时到 0.05 秒。
- 主干：奶茶翻倍（×2/级）、MP 翻倍（×5/级）、PP 翻倍（×5/级）、净化翻倍（×10/级）。
- 叶子：产量共鸣、净化共鸣、升级折扣、科技折扣、深渊易伤、先手优势、离线削弱、时间感知。
- 角色树：每角色 9 节点，5 层，成本 `2^(层-1)` AP，可重置返还。

## 七·补、成就

- 数据在 `src/achievements.js`：36 个成就，按覆灭 / 守护 / 地名 / 产量 / 单轮 / 手动生产 / 升级总等级 / 树节点 / 资源 / 万事屋 / 通关分类。
- **每个成就为全体角色提供 +100%**：达成 N 个 → 全产量与战力 ×(1+N)。最多 36 个 → ×37。
- 永久保留（属于 249 的记忆库，覆灭不清空）。
- 引擎每 tick 扫一遍未达成的成就，达成即生效；界面顶部「成就」页签显示进度与全部列表。

## 九、剧情系统

- 数据在 `src/story.js`。条目：`{ id, trigger, mode, speaker?, title?, lines[] }`。
- `trigger`：`restart`（进店 / 覆灭重开）、`guard`、`collapse`、`win`、`cond`（每 0.5s 轮询，支持 all/any）。
- `mode`：`fullscreen`（可带 title）/ `bottom`（可带 speaker）。
- `lines` 支持 `{ speaker, text }`，逐段切换说话人；`\n` 为段内换行。
- `repeat: true` 的条目每次触发都播；设置页可「跳过已读文本」。
- 播放时暂停，播完自动继续；离线时自动跳过。
