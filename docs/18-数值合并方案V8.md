## 5. V5 → V8 的机制差异（哪些旧概念消失）

- 四层 → **八层 + 终局**；`targets` 从 Number 变字符串 + Scientific（`2.49e2492` 不能写成 Number）。
- 32 项 → **64 项**；旧层项在高层按 `k=8·10^(l-o)` 重新开买，等级可到**上亿**（第八层一阶峰值约 1.29e9）。
- `totals` 8 → **16**：`[a,b,c,d,e,f,g,j,sP,sD,cE,dE,bG,bE,eD,eE]`。
- 成功永久：每层占位倍率 `B_s` → **四个全局科技**（MP / MD / MS / MF，作用域互不串联）。
- 失败永久：F1–F4 → **n1–n8**，n1 公式重写，n5–n8 全新。
- 购买：只有逐级 → **≤4 层逐级、≥5 层阈值二分批量 + 逐级尾部**。
- tick 顺序：8 步 → **12 步**（压力挪到生产/回充/缓冲/侵蚀之后；攻击用 `h_old`；成功判定先于缓冲）。
- 通关：第四层成功即停 → **八层成功进终局，终局永不胜**，失败才结束一轮。
- 单位：`units=[1,1,10,100]` 的显示倍率 → 废除，改 `Phi_s` 展开。

## 9. 2026-10-30 修复：树 → 升级页空白 / 页面无限变长

**现象**：从「科技树」切回「升级」后，升级卡片不显示，页面高度持续增长（1049 → 2577 → 4372 …）。

**根因**：科技树用 vis-network，容器是手动 append 进 `<div ref="treeHost">` 的。切换子页时 Vue 2 会
「就地复用」同类型的 div（三个子页的根元素都是 div，没有 key），于是 `.c-tree-host` 被 patch 成
`.l-upgrade-cols`，残留的 canvas 就挂在升级页的栅格列里；之后每次 render 再 append 一个容器，
高度就一直涨。

**修复**（三处）：
1. `web/js/tree.js` 新增 `detach()`：销毁 vis 实例、`container.remove()`、清空引用；
2. `app.js` 的 `syncTree()` 在「不在科技树页」时先 `detach()`（放在 250ms 节流之前，否则切走时可能被节流挡住）；
3. 树容器加 `key="tech-tree-host"`，让 Vue 不复用该节点。

**回归**：`test/v8.e2e.mjs` 增加往返断言 —— 连续 3 次「科技树 → 升级」后
`vis 残留 == 0`、`升级卡片 == 8`、页面高度稳定（实测 1070 / 1070 / 1070）。
`ok(...)` 全绿，截图 `common-back-to-upgrades.png`。

| 项 | 改前 | 改后 |
|---|---|---|
| 升级项的自动购买 | 科技页「自动购买」等级 > 0 即生效（默认 0 级） | 不变（0 级仍完全不自动） |
| 永久升级的自动购买 | `settle()` 结算时默认替玩家买 n1..n8 / 四项成功科技 | **默认只发币、不买**；科技树「自动化中枢」Lv1 解锁后才自动买 |
| MP 侧解锁方式 | 无（结算自动） | 中枢 Lv1：自动买「自动购买科技」+「专属永久升级」（每间隔各 1 级） |
| PP 侧解锁方式 | 无（结算自动） | 中枢 Lv4–7：自动买四个主干（净化效率 / 伤害效率 / MP 倍率 / PP 倍率） |
| 补手动的入口 | 无 | 科技页每个「专属永久升级」新增「手动升级」按钮（价格与结算同源） |

**数值安全的做法**：`settle(p, result, options)` 新增 `options.buy`，缺省 `true` —— 文档 §10.2/§10.3 的
基准路径（`campaign()`、参考模拟器、`v8-verify`）完全不变；只有引擎在**非 headless**（真实游玩）
且中枢未解锁时才传 `buy: false`。所以零容差对拍继续成立。

**验收**：`v8-audit` 增加 7 项（未解锁不花钱 / 钱留在钱包 / 解锁后自动买 / 手动买生效），
总数 8002 项；`v8.e2e` 增加「科技页有手动升级按钮 + 未解锁提示 + 点击后等级 +1」；
`scene()` 的默认自动购买等级从 22 改为 0，截图口径与真实开局一致。
