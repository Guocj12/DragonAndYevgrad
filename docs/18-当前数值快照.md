```js

```

深渊速率（对数空间）：

```
rate(tier, t) = span / (ln(1 + T/t0) × (t + t0))
span = 本档上限对数 − 本档起点对数
```

## 三、产物（分段函数，核心）

`src/engine.js` 的 `computeBonuses()` 末尾：

```js
const n = 本档覆灭次数 + 1;
const perRun  = tierCapLog(tier) * 0.5 * TUNING.aimStep;        // 每轮推进深渊起点的 10%
const baseLog = perRun - log10(TUNING.tauByTier[tier] || tau);  // 扣掉时长因子
prodTotal = 10 ^ (baseLog × n);                                  // 直接给出
```

```js
aimStep: 0.1
```

档 0 每轮目标产量：`1e10 → 1e22.5 → 1e35 → …`（每轮 +12.5 数量级 = 起点 124.7 的 10%）。

**目标曲线**：第 N 轮净化率 = N × 10%，10 轮清空进下一档。

## 五、科技

```js
techRampMax: 5       // 每级科技最多给 10^5
```

科技单级倍率随等级渐进：

```
ramp(lv) = 0.3 + (5 − 0.3) × lv / (lv + 100)
每级效果 = 10^(ramp × lv)
```

- 等级 0 起步 ×2（10^0.3）
- 等级 100 → 每级 10^2.65
- 等级 1000 → 每级 10^4.6（趋于上限 10^5）

科技上限 `maxLevel = 20`（`db.js` 末尾统一设置）。
