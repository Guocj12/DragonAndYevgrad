## 五、结算公式（`src/engine.js`）

| 项 | 公式 |
|---|---|
| 深渊上限 | `cap(k) = 2.49 × 10^E`，E = 249 / 2492 / 24920 / 249209 |
| 起始深渊 | `start = 0.5 × log10(cap)`（先手优势每级 ×0.9） |
| 深渊增长 | `log10 S += D · e^(t/τ) / τ · dt`，τ = 249/ln2 |
| MP 结算 | `floor((1 + 8 × 本轮最高净化率) × MP 倍率)` |
| PP 结算 | `floor(12 × (档位 + 1) × PP 倍率)` |
| AP 结算 | 每档首次守护 1 / 2 / 4 / 8；首次覆灭 1 |
| 产量 | 各乘区相乘（249 主链 × 独立产线 × 通用树 …） |
| 净化量 | `产量 × 净化效率 + 战斗伤害` |
