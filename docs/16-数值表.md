## 三、两套永久体系

### 3.1 失败永久 F（记忆点数 MP 购买，覆灭结算自动购买）

| 层 | 名字 | 成本公式 | 等级 0–5 的价格 | 机制 |
|---:|---|---|---|---|
| 1 | 记忆库 | ceil(4·1.35^n) | 4 / 6 / 8 / 10 / 14 / 18 | 第 1 层有效总等级抬高生产（log1p((a+b)/20)·1.6·F1） |
| 2 | 人情账 | ceil(40·1.35^n) | 40 / 54 / 73 / 99 / 133 / 180 | 两个原始生产来源互相借用 share=F2/(3+F2) |
| 3 | 手感 | ceil(400·1.35^n) | 400 / 540 / 730 / 985 / 1329 / 1794 | 每第 5 次削减强化 1+3·ln(1+F3) |
| 4 | 长跑 | ceil(8000·1.35^n) | 8000 / 10800 / 14581 / 19684 / 26573 / 35873 | 削减随整程时间 1+0.5·ln(1+F4)·sqrt(runTime/600) |

失败奖励：`QF = floor(4·10^(s-1+p))`，第一层 `p = log10(peak)/log10(b1)`，其他层 `p = (peak-1)/(b-1)`。

## 四、公式速查

```text
firstBonus = s==1 ? exp(1.6·F1·ln(1+(a+b)/20)) : 1+0.08·(1.6·F1·ln(1+(a+b)/20))
rawFirst   = s==1 ? 1.5^a · firstBonus : (1+a) · firstBonus
rawSecond  = 1 + 3c          share = F2/(3+F2)
first      = rawFirst  + (s>=2 ? share·(rawSecond-1) : 0)
second     = rawSecond + share·(rawFirst-1)
global     = sqrt(1 + d/10)  eta = sqrt(1 + b/10)
P          = α[s]·B_s·global·(s==1 ? first : first+second-1)
x += P·dt                    r += eta·P·dt
frequency  = min(20, 1+2g)   overflow = sqrt(max(1,(1+2g)/20))
timeMul    = 1 + 0.5·ln(1+F4)·sqrt(runTime/600)
hit        = B_s·global·(1+e)·overflow·timeMul·(1 + ln(1+j)/10·sqrt(h/10))
burst      = 1 + 3·ln(1+F3)  （片段第 5/10/15… 次攻击替换使用）
removed    = min(h,hit)      h -= removed   r += 0.1·ln(1+f)·ln(1+removed)
h += q_s(t)·dt               t 用当前层时间；F4 用整程时间
```
