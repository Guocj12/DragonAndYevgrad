## 1. 深渊

```
S0   = cap^0.5                    // 开局 50% 指数进度
D    = log10(cap) - log10(S0)     // 本档跨度
τ    = 249 / ln(2) = 359.3 s      // 零产量时 249 秒涨满
f(t) = e^(t/τ) - 1

log10 S(t) = log10(S0) + D · f(t)
```

每 tick：

```
rate = D · e^(t/τ) / τ            // 数量级/秒，随 t 指数增长
S   *= 10^(rate · 0.05)           // 增长
S   -= P · 0.05                   // 净化
if S >= cap → 覆灭，回档 0
if S <= 0   → 守护，上限 +1 档
```

| 档 | cap | 指数 |
|---|---|---|
| 0 | 2.49e249 | 249 |
| 1 | 2.49e2492 | 2492 |
| 2 | 2.49e24920 | 24920 |
| 3 | 2.49e249209 | 249209 |

| 5 | 2.49e24920949 | 24920949 |

## 2. 资源

| 资源 | 获取公式 |
|---|---|
| mtc | `产量 × dt` 累加 |
| MP | 覆灭时 `1 + floor(净化率 × 5)`，净化率 = `1 - S/cap` 的历史最低值 |
| PP | 守护时 `10 × (档位 + 1)` |
| AP | 每档首次守护 / 首次覆灭：档 0 = +1/+1，档 1 = +2/+1，档 2 = +4/+1，档 3 = +8/+1 |

资源倍率（通用树、科技、科技树）全部相乘。

## 7. 恒

**基础**：每秒 1 次攻击；攻速 > 20/s 的部分自动转伤害。

```
power  = 10 × (S/S0)^α × 1.5^L1 × Π(其他战力倍率)
damage = power × 0.1 × 钉刺 × Π(其他伤害倍率)
α      = (0.30 + 0.02·L2) × (1 + 0.01·L5) × (1 + 0.01·ΣL)^(0.1·L8)
```

攻速超过 20/s 时：

```
有效伤害 = damage × 攻速 / 20
```

## 9. 结算顺序

每个 tick（0.05s）：

```
1. 产量累加：mtc += 产量 × 0.05
2. 战斗结算：S -= (P_奶茶 + P_白琦 + P_恒) × 0.05
3. 深渊增长：S *= 10^(rate × 0.05)
4. 边界判定：S >= cap → 覆灭；S <= 0 → 守护
5. 资源结算：MP/PP/AP 按条件发放
```
